# H8 — Ator de sistema

`SYSTEM_ACTOR_CONTRACT=NOT_APPLICABLE` para a V1. A H8 projeta notificacoes
diretamente para o usuario destinatario e nao cria Nota, Auditoria ou usuario
tecnico falso. Quando um evento automatico exigir auditoria adicional em fase
futura, devera reutilizar a identidade canonica existente do sistema.
